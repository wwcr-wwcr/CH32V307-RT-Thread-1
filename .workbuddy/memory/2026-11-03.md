## ui_designer 加横屏模式

顶栏「方向」下拉：竖 320×480 / 横 480×320。实现要点：

- `M.ORIENT/W/H` 运行时改，`stage.style.width/height` 用内联样式覆盖 CSS 的 320×480 默认值。
- `clampAll()`：① 标题栏/提示条按新尺寸重排（hint 贴底 `M.H-46`）；② 顶层控件夹进画布；③ 子控件按**父容器**再夹一次（父可能刚被缩小）。
- 顶部副标题的尺寸用 `<b id="subSize">` 动态更新。
- `presetLed/presetDac` 末尾也调 `clampAll()`，横屏下点示例不会飞出画布。

### 顺手修的既有 bug
`addWidget()` 末尾原来用 `clamp(w.x, 0, M.W-8)` 做**绝对坐标**夹取，对子控件是错的——新控件放进卡片后会落到卡片外、被 `#stage` 的 `overflow:hidden` 裁掉（竖屏也一样，只是不明显）。改成按父容器 `PW/PH` 夹：`w.w=min(w.w,PW)` + `x=clamp(x,0,max(0,PW-w.w))`。

### 注意
画布比例**不会**写进生成的 C 代码。真机横屏要 LCD 驱动支持旋转（ST7796S 需改 MADCTL / 分辨率参数），设计器这边只是画布比例。

## ui_designer 支持选择父容器

原来 `pickHost()` 写死"最后一个 panel"，控件无处可逃。现在三条路径：

1. **属性面板「父容器」下拉**：列出所有 panel（排除自己与自己的子孙），选「（页面顶层）」可取出卡片。
2. **拖拽吸附**：`bindDrag` 的 `onUp` 里用 `hitPanel(w)` 判中心点落在哪张卡，自动 `setParent` 并 toast。title/hint 固定件不参与。
3. **新控件落点**：优先放进当前选中的 panel，没选中才回退到"最后一个 panel"。

`setParent()` 保持屏幕绝对位置（`absPos` 差值换算），装不下就缩并夹进新父容器。`isDescendant()` 防环：p1 塞进 p2 后，p2 的候选里不再出现 p1，但 p1 仍可选 p2（父级可移回）。

> 只有 panel 能当容器：`ui_card` 返回的是数值 label，`ui_plot_t*` 不是 lv_obj_t。
> 这也解释了"控件莫名消失"——子控件超出父容器被 LVGL 默认裁剪（`OVERFLOW_VISIBLE` 未开），下拉能看到它属于谁。

### 坐标乱飞：4 个根因（已修）

1. **`pickHost()` 把绝对坐标当相对用**：返回 `x: p.x` / `y: p.y + 28`，addWidget 却当成相对父容器的坐标 → 偏移一个"父容器位置"。改成返回 `x: 0, y: 28 + n*36`。
2. **`delWidget()` 删父容器不换算子控件坐标**：只把 `parent=null`，孩子还带着相对旧父的坐标 → `ui_card(s_page, 168, 26, ...)` 这种飞掉的值。改成删除前用 `absPos(父)` 加到孩子坐标上再夹进画布。
3. **拖动允许负坐标**：`clamp(nx, -w/2, M.W-8)` → 生成 `y = -3`。改成 `clamp(nx, 0, max(0, W-w))`。
4. **plot 默认高度算错**：`top = host.y - host_.y`（相对减绝对）。改成 `top = host.y`。新增 `clampToParent()`，拖完仍在原父容器时夹回边界。

验证口径：`w.x + 父绝对x === absPos(w).x`，逐个控件比对过，改成相对坐标后全部一致。

### 父链自检 + 绝对坐标（补漏）

用户反馈"下拉只有页面顶层，但卡片视觉位置在 292、面板 Y=44" —— 说明 `parent` 指向了一个**存在但 type 不是 panel** 的对象（隐形容器），`hostCandidates` 只列 panel，所以下拉无匹配、退回第一项。

- `normalizeTree()`：父不存在 / 不是 panel / 成环 → 按当前 `absPos` 提升到页面顶层，视觉位置不变。`absPos` 加 `guard < 32` 防环死循环。
- `renderAll()` 开头和 `genCode()` 开头都调它（复制/下载也会走 genCode）。
- 属性面板 X/Y 下面加小字「屏幕绝对位置 (x, y)」，杜绝"44 vs 292"的困惑。
- 没有 panel 时下拉给提示；父失效时给红字。

### 坐标系重构（彻底解决"坐标飞"）

之前是"相对坐标 + 嵌套 DOM"，父容器位置被反复加/漏加，改了几次都没除根。**直接换模型**：

| 项 | 旧 | 新 |
|---|---|---|
| `w.x/w.y` | 相对父容器 | **绝对屏幕坐标** |
| 画布 DOM | 父容器嵌套子控件 | **扁平**，全部挂 stage，按数组顺序叠层 |
| 生成代码 | 直接用 w.x/w.y | `xyOf(w)` / `relXY(w)` 反算相对坐标 |
| 换父 / 删父 | 要换算坐标（易错） | **坐标不动**，只改 parent |
| 拖父容器 | 子控件不动 | `moveSubtree()` 带子孙一起走 |

关键函数：`relXY(w)` 出相对坐标、`xyOf(w)` 出 "x, y" 字符串（生成代码的 18 处全用它），`clampWithSubtree()` 夹取时同步子孙，`pickHost()` 返回父容器绝对几何 `{px,py,pw,ph,n}`。

注意 `ui_row(parent, y, ...)` 只传 y，生成时用的是 `relXY(w).y`（不是 xyOf）。

属性面板：X/Y 输入框 = 画布绝对位置，下面小字 ="代码里的坐标（相对 PANEL #2）：(0, 10)"，两边都能对上。

### 关掉自动归属（用户要求）

用户反馈"数据卡片坐标不对"（X=100 但代码里 160）。根因是 `w.parent` 指向一个非法对象时 `relXY` 仍然减了它的坐标。

两处自动归属全部移除：
- `pickHost()` 现在永远返回顶层 `{parent:null, px:0, py:90, pw:M.W, ph:M.H-HINT_H, n:顶层数}`，不再"选中卡片就进那张卡"
- `bindDrag` 的 onUp 不再调 `hitPanel()` 吸附，只做 `clampWithSubtree` 防出界

配套加固：`relXY()` 只在父是合法 panel 时才减偏移（否则按 0）；`normalizeTree()` 增加"自己指自己"和"父链成环"检测。

归属现在**只能**通过属性面板「父容器」下拉手动设置。

### 真正的根因：CSS position:relative（前面查数据全白费）

用户报"第二个数据卡 Y=0 却显示在第一个卡的高度"。

`.w{position:absolute}` 之后，`.w-slider/.w-bar/.w-card/.w-plot` 又写了 `position:relative`，
同级选择器后者胜 → 这几类控件**退回文档流**，会占位并互相顶开。
表现就是"第一个正常，第二个开始往上堆偏移量"，和 JSON 数据完全无关。

修复：删掉这 4 个 `.w-xxx` 里的 `position:relative`，让它们统一继承 `.w` 的 absolute。
（`#stage` / `#stageWrap` 的 relative 是定位基准，必须保留。）

验证口径：`getBoundingClientRect` 相对 stage 的偏移必须精确等于 `w.x / w.y`，5 类控件全部通过。

> 教训：坐标"看起来不对"时，先确认 DOM 的 offsetParent 和 computed position，再怀疑数据。
