## menu.c 加入「后台常驻任务」（5 处，468 行）

需求：某些 task 退出页面后线程继续跑（编码器倒计时），且这类任务关掉后不会再打开。

1. `#define TASK_EVT_BG 3`
2. 任务表后面加 `g_bg_list[]` 白名单 + `task_keep_alive()`（指针比较，不用字符串）
3. `menu_exit()`：命中白名单时不调 `task_stop`，只发 `TASK_EVT_BG`，照常 `menu_draw_list` + `ui_destroy`
4. `task_entry()`：局部 `uint8_t bg`，`bg != 0` 时只跑 `update` + `rt_thread_mdelay(10)`，不再收事件
5. `task_entry()`：收到 `TASK_EVT_BG` 时 `bg = 1; continue;`

`bg` 是线程局部变量，白名单放多个任务互不干扰。白名单初始为空（`RT_NULL` 占位），因为 mic_fft / uart_plot 都吃 ADC，后台跑会互相踢配置。

## 教训

- bash 里用 `python -c "...反引号..."` 会被 shell 做命令替换，写日志/代码时不要用反引号包中文变量名。改用 Write 工具写文件。
- 用户给的引用路径才是准的，不要沿用上一轮的路径。
