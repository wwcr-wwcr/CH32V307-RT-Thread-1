## 把 lv_font_conv 打包成 Windows 单文件 exe

目标：`D:\eample_task\tools\lv_font_conv.exe`，不依赖 Node.js 就能生成 LVGL 字库。

### 走过的弯路

1. `npm install --omit=dev` 失败：package.json 的 `prepare` 钩子会跑 `build:browser`，需要 devDependencies（browserify）。加 `--ignore-scripts` 解决。
2. `pkg` 打包卡死：要下载 `node18-win-x64` 运行时（约 40MB），半小时只下了 2.9MB，放弃。
3. 最终方案 **Node 22 自带的 SEA**（Single Executable Application），复用本机 node.exe，不需要额外下载运行时。

### 最终流程（全部在 `D:/eample_task/tools/lvfont/`）

```bash
git clone --depth 1 https://github.com/lvgl/lv_font_conv.git .
npm install --omit=dev --ignore-scripts
npm i -D esbuild postject --ignore-scripts

npx esbuild lv_font_conv.js --bundle --platform=node --target=node18 --format=cjs --outfile=bundle.js
node --experimental-sea-config sea-config.json          # → sea-prep.blob (1.3MB)
cp "$(which node)" lv_font_conv.exe                     # 84MB，node 22.22.2
npx postject lv_font_conv.exe NODE_SEA_BLOB sea-prep.blob \
   --sentinel-fuse NODE_SEA_FUSE_fce680ab2cc467b6e072b8b5df1996b2
```

产物 85MB，`--version` 输出 1.5.3，中文生成测试通过（16 字 → 15KB .c）。

### 交付

- `tools/lv_font_conv.exe`（85MB）
- `tools/lv_font_conv_用法.md`（命令、体积对照、LVGL 接入、`-fexec-charset=UTF-8` 编码坑）
- `tools/lvfont/` 源码 + node_modules 约 409MB，只用于重新打包，可随时删

### 要点

- 中文字库必须 `--symbols` 子集化，16px/4bpp 每字约 0.9KB；全量 3500 字约 450KB，256KB Flash 装不下。
- 字库默认不含 ASCII，要加 `--range 0x20-0x7F`，否则界面上的数字会变方块。
- 工程源码是 GBK，LVGL 按 UTF-8 解析，必须在 MRS 加 `-finput-charset=GBK -fexec-charset=UTF-8`，否则字库有字也显示方块。
- bash 里写文件别用反引号（会被 shell 做命令替换），改用 Write 工具。


## 新增 HAL/MSH/msh_tool.c（msh 调试命令集）

13 条命令，全部 MSH_CMD_EXPORT_ALIAS 自注册，命令名 = 别名（不是函数名）：
heap / uptime / rst / led / beep / seg / lux / adc / keys / i2cscan / u3tx / u3rx / u3loop

设计要点：
- 每条命令自己 lazy init 对应外设（static 标志），不依赖 main 先初始化过
- msh 线程栈只有 1024，命令里一律用 static 缓冲，不开大局部数组
- u3tx 用 rt_strncat 拼接多参数（避开 rt_snprintf 返回值坑），末尾自动加 CRLF
- u3loop 发 A-Z 循环序列，短接 PB10-PB11 后比对，打印 PASS/FAIL

工程是 FINSH_USING_MSH_ONLY，命令名长度受 FINSH_NAME_MAX 限制，都控制在 8 字符内。
编译验证：-Wall -Wextra 零警告。HAL/MSH 是新目录，MRS 里要按 F5 刷新才会进编译。


## 新建 D:/example_easy（串口看数系列，7 个简单 task）

定位：每个任务只读一个外设、屏幕显示一个数、同时往 msh 串口打一行，用来做「第一次接外设」的连通性验证。

任务：task_easy_lux / mic / seg / beep / led / tone / monitor（线程名 ELUX/EMIC/ESEG/EBEEP/ELED/ETONE/EMON）

设计：
- 全部照 task_example 的 app_t + s_view + view_push + app_event 七回调骨架
- 7 个任务共用一个极简 UI（src/ui/task_easy_ui.c），接口 easy_ui_render(title, main, sub)，避免 21 个文件
- 输出走 rt_kprintf（uart1 = msh 口），不是 uart3
- monitor 输出 CSV 格式 lux,mic,db,key，K3 打表头方便粘 Excel

编译：8 个文件 -Wall -Wextra 零警告（用工程头文件 + -I D:/example_easy/src 直接验证，未装进工程）。

README 里写了安装三步（拷文件 / task.h extern / g_task_list 注册）。

注意：mic 和 monitor 里 log10f 会链接 libm；tone 用 audio_* 与 dac.h 抢 TIM4。
