## 改成「U 盘主仓库」方案（不要远程仓库）

用户明确不要 GitHub/Gitee，要 U 盘和电脑同步，主仓库放 U 盘。

- 主仓库（裸库）：`D:/主文件/主仓库.git`（D 盘是 thinkplus U 盘，FAT32，29.3G）
- 电脑工作区：工程根目录，origin 直接指向上面那个路径（本地路径当 remote 用）
- 一键同步 = pull --rebase --autostash + push；一键上传 = add/commit + push
- 换电脑：`git clone D:/主文件/主仓库.git` 即可

### 踩坑：FAT32 上的仓库被 git 判成"别人的"（dubious ownership）
git 2.35+ 对不属于当前用户的仓库拒绝操作，push 直接 `Could not read from remote repository`，
提示要 `git config --global --add safe.directory <path>`。命令行 `-c safe.directory=` 对
接收端进程不生效，只能写全局。已给 `D:/主文件/主仓库.git` 登记了一条（不是 '*'），
工具里 `ensure_safe_dir()` 每次推送前会自检补登。

### 踩坑：`* -text` 会让 git 把所有文件当二进制
表现：改一个字符，`git show --stat` 显示 `Bin 5093 -> 6378 bytes`，diff 看不到内容。
改成 `* -text diff` —— text 属性仍为 false（不转换换行，GBK+CRLF 安全），
但 diff 属性为 true，按文本显示差异。

### 工具升级（GitTool v2）

- 黄条提示：没设主仓库 / 设了但读不到
- 「查找 U 盘」：扫可移动盘（GetDriveTypeW==2）的 根/主文件/git/GitTool 下一层找 *.git
- 「创建主仓库」：init --bare + symbolic-ref HEAD refs/heads/main + set-url + push -u
